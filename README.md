# SkyBlock JP

Hypixel SkyBlockのアイテム説明・メニュー案内・NPC会話を日本語で表示する、Minecraft 26.2向けの非公式Fabric modです。同梱辞書を優先して使い、登録済みの訳はAPIキーなしで表示します。固有名詞と数値ステータスは英語のまま残します。

## 導入

1. Minecraft **26.2 / Java 25**とFabric Loader **0.19.5以上**を用意します。
2. [Releases](https://github.com/bibi09ix/skyblock-jp/releases)から、そのMinecraft版向けのJARを取得します。`sources`付きのJARは開発用です。
3. ゲームフォルダーの`mods`へJARと対応するFabric APIを入れます。SkyBlock JPの旧JARがある場合は、同じmodが二重にならないよう差し替えます。
4. 起動後、**F8**で設定を開けます。新規設定では同梱辞書と登録済み説明の即表示がONです。既存設定の明示的なOFFは変更しません。

初回案内の「辞書だけで使う」を選ぶと、辞書をON、外部API翻訳をOFFにして保存します。Groqキーの作成は任意です。辞書には未検証の訳や未収録の文があり、ゲーム全体を翻訳できるものではありません。

## 基本操作

| 操作 | 動作 |
|---|---|
| アイテムへカーソルを合わせる | 辞書に一致する説明段落を最初のツールチップから表示 |
| **G** | そのアイテムの残りの説明を翻訳要求 |
| **Ctrl + G** | 辞書を迂回し、アイテム原文をAPIへ再送して再翻訳 |
| **Shift**を押して表示 | 元の英語のツールチップを確認 |
| チャットを開き、本文へカーソルを合わせて**G** | 選んだメッセージを手動翻訳 |
| **F8** | 辞書・API・チャット/HUD・更新・共有ログの設定 |

Gは初期割り当てです。F8で変更できます。チャットの翻訳案内は既存のホバー情報へ追加し、クリック機能は保持します。チャット本文に翻訳ボタンを挿入する方式ではありません。

## 翻訳する範囲

- **アイテムとメニュー:** 説明段落と登録済みの案内を翻訳します。名称・数値ステータス・識別子・他modの補助情報等には英語を残します。未登録の説明は原文のままです。アイテムを見ただけで外部APIへ送信するバックグラウンド翻訳はありません。
- **NPC会話と選択肢:** 設定がONなら自動翻訳します。辞書を先に調べ、未一致の場合は外部API設定に従います。
- **固定システム通知:** 登録済みの文をローカルの辞書で置き換えます。
- **プレイヤーチャット:** 自動翻訳はせず、チャット上のGで選んだ本文を要求します。
- スコアボード、アクションバー、タイトル、ボスバー、エンティティ名の全面翻訳は現在の対象外です。

辞書は全文・正規化・型付きテンプレートと、話者や画面の条件を使って照合します。数値・名前・コマンド・意味の対応や元の色を確認できない場合は、その部分を原文で残します。API訳は検証に失敗した候補を暫定表示する場合があり、辞書訳と同じ採用保証ではありません。失敗理由はログで確認できます。

## 外部APIの利用と送信内容

F8の「外部API翻訳」をOFFにすると、外部翻訳への通信と保存済みAPI訳の表示を止め、辞書・端末内の定型訳だけを使います。キーとキャッシュは削除しません。自動更新のGitHub通信は別の設定です。

APIを使う場合は、次の内容を**選択したGroqまたはGoogle**へ送信します。

- NPCの未登録の台詞。Groqでは話者と直前の会話も文脈に使います。台詞内にプレイヤー名等が含まれることがあります。
- Gで要求したアイテムの説明段落、または選んだチャット本文。チャットには他の人が書いた内容や名前が含まれる場合があります。
- 接続テスト時の確認用短文。Ctrl＋Gの再翻訳もAPIを使います。

初期のプロバイダー選択はGroqです。F8のキー入力欄の「設定ヘルプ」から取得手順を開けます。Googleはキーなしで選べます。外部サービス側の利用条件・保存・データ取扱いは各提供元を確認してください。モデル、利用枠、応答品質はサービスによって変わります。

Groq APIキーはゲームフォルダー内の設定JSONへ平文で保存し、画面では伏せ字にします。設定ファイルやゲームフォルダー全体をそのまま他人へ渡さないでください。

## 翻訳HUDと設定

F8 →「チャット・HUD設定」で、翻訳を別HUDへ出すか、位置・幅・文字サイズ・行数・背景透明度・表示時間を選べます。「消えない」も選択でき、チャットを開くと履歴を確認できます。HUDは話者と本文を分けて表示します。

「同梱辞書」では即表示と照合理由ログを設定します。「本文の標準色」が「対象なし」の場合、現在の辞書には色の降格を許可した箇所がなく、この設定は現在の訳へ影響しません。

## 問題の報告

F8の**「共有用ログZIPを書き出す」**で、専用の診断ログをゲームフォルダー内の`skyblock-jp-reports`へ保存できます。作成後も自動送信しません。

設定・APIキー・個人チャット・翻訳キャッシュ・`latest.log`は共有ZIPへ入れません。NPC台詞やアイテム情報には名前が残る場合があるため、渡す前に内容を確認してください。報告には、起きた画面・操作・期待した表示とZIPを添えると調査しやすくなります。

書き出しを押した時点で待機中の診断ログは、バックグラウンドで保存完了を待ってからZIPにします。保存の失敗や待機時間超過時は、その理由を表示して再試行を案内します。翻訳APIの応答完了まで待つ操作ではありません。

## 自動更新

初期値はONです。GitHub Releasesの版別更新情報とJARを確認し、ダウンロードした更新をゲーム終了後に適用します。次の起動で新版になり、設定とAPIキーを保持します。F8 →「自動更新」でOFFや手動確認を選べます。

JARのハッシュ・mod ID・Minecraft版等を検証しますが、配布元と独立した署名検証は現時点でありません。取得元はこのプロジェクトの公開リリースを使ってください。
