## 翻訳の動作

- アイテム名、数値ステータス、Ability見出し、エンチャント一覧、レア度は原文を保持します。
- 英語の説明文は、空行やステータス行で区切られた段落単位で結合して翻訳します。
- 日本語訳は元の色・スタイルを保持しながら描画幅に合わせて折り返します。AIが色の対応を誤る可能性はあるため、Shiftで原文と比較できます。
- Shiftを押すと元のツールチップを表示します。
- NPCの `[NPC] 名前: 台詞` は英語を残して、その下に日本語を追加します。別メッセージとして届くNPCの台詞は別々に翻訳します。
- 他プレイヤーのチャットや送信チャットは翻訳しません。
- 初回の翻訳中や失敗時は原文を表示します。失敗はlatest.logに理由を記録し、本文・訳文を診断用に記録します。APIキーは伏せます。

## 設定

ゲームディレクトリの `config/skyblock_jp/config.json` に保存します。

```json
{
  "enabled": true,
  "npcTranslation": true,
  "loreTranslation": true,
  "hypixelOnly": true,
  "provider": "GOOGLE",
  "groqModel": "openai/gpt-oss-120b",
  "groqApiKey": "",
  "wrapWidth": 260
}
```

GoogleはAPIキー不要のオンライン翻訳です。Groqは `provider` を `GROQ` にしてキーと利用可能なモデルIDを設定します。
翻訳対象の説明文・NPC台詞は選択したサービスへ送信されます。Groqの料金・利用上限は利用者の契約によります。
APIキーは設定ファイルに保存されます。このファイルをソースZIPや共有ログに含めないでください。

APIリクエストは1件ずつ送信し、最大256件を待ち行列に保持します。同じ段落は重複送信しません。
通信エラーやHTTP 429/5xxは最大3回まで試行します。失敗した段落は60秒後から再試行可能になります。
キャッシュは言語・プロバイダー・モデル・段落をキーとしてローカル保存します。
訳文の数字が元の文章と一致しない場合は採用しません。

## 制限と確認状況

説明文の判定は控えめなルールによるものです。未知の形式は未翻訳になったり、見出しを説明文と判定する場合があります。
空行のない別の説明文は一つの段落として扱います。Google翻訳では文中のステータス名まで翻訳されることがあります。
数値行自体は翻訳に送りませんが、すべてのSkyBlockアイテムの形式を網羅した保証はありません。
SkyHanni等が追加した説明文も分類の対象になります。

ビルドおよび15件の自動テストを実施しました。Groq GPT OSS 120Bへの色・数値マーカー付き翻訳通信も確認済みです。ゲーム内の見た目・操作は未検証です。
旧SkyBlock TranslatorとNPC & Items Translatorは同時利用しないでください（重複を防ぐためFabric依存関係で排他指定しています）。
