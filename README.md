# SkyBlock JP 0.6.4



## 0.6.4の変更

- GitHub Releases経由の自動更新を追加。起動時に確認し、新版があればMinecraft 26.2・mod ID・版番号・SHA-256を検証して保存。ゲーム終了後に独立したJavaヘルパーが旧JARをバックアップして差し替えます。設定・APIキー・キャッシュは保持します。
- F8設定右上の「自動更新」からON/OFFと手動確認。配布用JARには公開リポジトリ名を埋め込めるため、通常は利用者によるURL設定は不要です。
- 開発者向け公開手順はDISTRIBUTION.mdを参照。旧0.6.3以前の利用者には、自動更新対応版を一度だけ導入してもらう必要があります。

## 0.6.3の変更

- HUD配置画面にも文字サイズスライダーを追加。プレビューに即反映し、保存／キャンセルに対応。「初期値」は文字サイズも100%へ戻します。
- バックグラウンドのアイテム事前翻訳を追加（初期値ON）。F8 → チャット・HUD設定 → バックグラウンド翻訳でON/OFF・待機時間・段落ごとの間隔を調整できます。
- 初期値は翻訳・別アイテムの閲覧から120秒待機、180秒につき1段落。直近20アイテムを新しい順に処理し、キャッシュ済み段落はスキップ。サーバー接続が変わると履歴を破棄します。
- 手動・NPC翻訳と設定操作を優先。バックグラウンドの通信失敗は即再試行せず15分休止します。APIキー未設定時は処理しません。API利用枠を消費し、レート上限に達しない保証はありません。
- 1アイテムの全段落が揃った後だけ日本語表示。失敗した段落はその接続中に自動再試行せず、G/Ctrl+Gによる手動処理は利用できます。原文・訳文はbackground-translations.jsonl、失敗は既存の詳細ログに記録します。

## 0.6.2の変更

- F8 → チャット・HUD設定に文字サイズスライダー（75〜250%）を追加。初期値・既存設定は100%です。

- 枠幅は独立して変更できます。大きな文字が枠からはみ出さないよう描画を切り抜きます。

- HUD配置画面の「初期値」も新しいレイアウトへ更新しました。

## 0.5.1の変更と使い方

- F8 →「チャット・HUD設定」→「HUDの位置・大きさを調整」。枠をドラッグして移動し、右下の青い角をドラッグして幅と高さ（最大行数）を変更できます。「保存して戻る」でその場で反映します。
- 位置調整のドラッグ開始登録を修正。チャット・HUD設定も「保存して戻る」で直接保存するので、元の画面で再保存する必要はありません。
- 背景の透明度を0〜100%のスライダーで調整できます。100%で背景が完全に透明になります。文字の色・透明度には影響しません。
- 表示時間は15〜120秒と「消えない」を選択できます。「消えない」は設定ファイルではhudSeconds=0です。
- チャットを開くと、表示期限が過ぎた訳文も履歴として表示します。HUDの枠内にカーソルを置いてホイール操作で遡れます。最大200件を保持し、接続変更・ゲーム終了で消去します。
- 数字付きユーザー名・ランク・アイコンを含むチャットのヘッダーを一体で保持します。API返答のJSONの包みを除去してから全文のマーカーを検査し、形式の漏れや欠落を防ぎます。
- 死亡通知はローカルの定型訳で主語と相手・元の色を保持します。座標だけの通知もAPI送信を省き、そのまま表示します。
- 募集のlf・p me・lowballingをチャット用に指示し、不明な装備略語を勝手に展開しないよう調整しました。自然言語の訳質には揺れが残ります。
- hud-display.jsonlに実際の表示行・改行・位置・幅・背景不透明度・履歴スクロールを記録します。変更があるときだけ非同期記録し、2MBでローテーションします。
- 手動チャットのキャッシュのみ世代を更新しました。NPC・アイテムのキャッシュは維持します。
- キーやモデルを編集中にHUDだけ保存した場合、キー・モデルの未保存変更はそのまま保持します。APIの変更はメイン設定で保存してください。

## 0.5.0の変更と使い方

- F8 →「チャット・HUD設定」→「別HUD表示」をONにすると、翻訳結果を専用HUDへ表示します。OFFなら従来の[JP]チャット表示です。原文はチャットに残ります。
- 「HUDの位置をドラッグで調整」で枠を移動し「この位置にする」を押します。設定画面へ戻って保存してください。幅・最大行数・表示時間も変更できます。
- 各チャットメッセージの[訳]を、チャットを開いてクリックするとそのメッセージだけ翻訳します。NPC以外のプレイヤー会話、サーバー通知、modのメッセージにも対応。ボタンはON/OFF、先頭/最後尾を切り替えられ、保存後に現在のチャット履歴も更新します。
- すでに生成した[JP]訳文や空白だけの行には、繰り返し翻訳を避けるためボタンを付けません。古い履歴が保持上限500件から外れた場合はローカル通知します。
- 翻訳ボタンはローカルのランダムなメッセージIDを参照し、翻訳操作のコマンドや原文をMinecraftサーバーへ送信しません。クリックした文章は、設定した翻訳APIへ送信します。
- APIキー欄の右の「設定ヘルプ」で、APIの選択→ログイン→キー発行→貼り付け→接続テストまで5段階の案内を開きます。キー発行は利用者が公式サイトで行います。
- 公式リンク: [Groqのキー管理](https://console.groq.com/keys)、[公式の手順](https://console.groq.com/docs/quickstart)。
- NPCでは同じ話者の45秒以内の直前の発言を参照します。接続変更時に履歴をリセットし、別の話者・古い会話を混ぜません。手動の翻訳ボタンには、その行に対応する会話文脈を記録します。
- 原文に色タグがない場合だけ、APIが勝手に追加した色タグを除去。元の数値・固有名詞のマーカーは引き続き検証します。色付き原文のタグを無条件に削除することはありません。
- 接続句の未訳、保護した名前の重複、番号範囲の分断、Chocolateの表、種類数の意味、日本語の重複した語尾を改善しました。
- プレイヤー名・URL・コマンドも原文から保護します。HUD位置は画面サイズに対する比率で保存し、解像度変更時も画面内へ収めます。
- NPCログはnpc-translations.jsonl、手動チャットはchat-translations.jsonl。原文・訳文・参照した直前の発言・色タグを記録します。キャッシュの世代を更新したため初回は翻訳APIへ再送されます。

- 設定画面から全体・NPC・アイテム翻訳のオン/オフ、翻訳キー、API、GroqモデルID、APIキーを変更できます。
- 「保存して接続テスト」は短い例文をAPIに送信します。Groqの場合、通常の利用枠を消費します。
- 「推奨モデルを選ぶ」は `openai/gpt-oss-120b` を入力します。APIキーは伏せ字表示です。
- エラー時はツールチップにも原因を表示します。翻訳キーを押し直すと再試行します。
- ステータスの原文保持と、段落単位の翻訳はそのままです。

Minecraft 26.1.2 / Fabric Loader 0.19.5以上 / Fabric API / Java 25 用の独立したクライアントMODです。
既存の翻訳MODのソースコードやJARを改変・同梱していません。

## 翻訳の動作

- アイテム名、数値ステータス、Ability見出し、エンチャント一覧、レア度は原文を保持します。
- 英語の説明文は、空行やステータス行で区切られた段落単位で結合して翻訳します。
- 日本語訳は元の色・スタイルを保持しながら描画幅に合わせて折り返します。AIが色の対応を誤る可能性はあるため、Shiftで原文と比較できます。
- Shiftを押すと元のツールチップを表示します。
- NPCの `[NPC] 名前: 台詞` は英語を残して、その下に日本語を追加します。別メッセージとして届くNPCの台詞は別々に翻訳します。
- 他プレイヤーのチャットや送信チャットは翻訳しません。
- 初回の翻訳中や失敗時は原文を表示します。失敗はlatest.logに理由を記録し、本文・訳文を診断用に記録します。APIキーは伏せます。

## 操作

`/sbjp` または F8 : 設定GUIを表示

`/sbjp toggle` : 翻訳の一時オン・オフ（再起動では設定ファイルの値に戻ります）

`/sbjp reload` : 設定を再読み込み

## 設定

ゲームディレクトリの `config/skyblock_jp/config.json` に保存します。

```json
{
  "enabled": true,
  "npcTranslation": true,
  "loreTranslation": true,
  "hypixelOnly": true,
  "provider": "GOOGLE",
  "groqModel": "openai/gpt-oss-120b",
  "groqApiKey": "",
  "wrapWidth": 260
}
```

GoogleはAPIキー不要のオンライン翻訳です。Groqは `provider` を `GROQ` にしてキーと利用可能なモデルIDを設定します。
翻訳対象の説明文・NPC台詞は選択したサービスへ送信されます。Groqの料金・利用上限は利用者の契約によります。
APIキーは設定ファイルに保存されます。このファイルをソースZIPや共有ログに含めないでください。

APIリクエストは1件ずつ送信し、最大256件を待ち行列に保持します。同じ段落は重複送信しません。
通信エラーやHTTP 429/5xxは最大3回まで試行します。失敗した段落は60秒後から再試行可能になります。
キャッシュは言語・プロバイダー・モデル・段落をキーとしてローカル保存します。
訳文の数字が元の文章と一致しない場合は採用しません。

## 制限と確認状況

説明文の判定は控えめなルールによるものです。未知の形式は未翻訳になったり、見出しを説明文と判定する場合があります。
空行のない別の説明文は一つの段落として扱います。Google翻訳では文中のステータス名まで翻訳されることがあります。
数値行自体は翻訳に送りませんが、すべてのSkyBlockアイテムの形式を網羅した保証はありません。
SkyHanni等が追加した説明文も分類の対象になります。

ビルドおよび15件の自動テストを実施しました。Groq GPT OSS 120Bへの色・数値マーカー付き翻訳通信も確認済みです。ゲーム内の見た目・操作は未検証です。
旧SkyBlock TranslatorとNPC & Items Translatorは同時利用しないでください（重複を防ぐためFabric依存関係で排他指定しています）。

## 失敗の詳細ログ
latest.log および config/skyblock_jp/translation-failures.jsonl に、各試行のアイテム名・対象行・原文・訳文・モデル・原因を保存します。マーカーの欠落/追加/閉じ順、数値変化、日本語なし、空の返答、HTTPエラーを区別します。APIキーは伏せます。専用ログは2MBで1世代ローテーションします。以前の失敗の本文は復元できません。
