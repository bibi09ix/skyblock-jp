# Dictionary source attribution

This bundled candidate is a Japanese adaptation of saved public Hypixel SkyBlock text. It is not an official Hypixel translation. The MIT license for this mod's code does not replace the source materials' terms.

- NotEnoughUpdates-REPO: https://github.com/NotEnoughUpdates/NotEnoughUpdates-REPO, pinned commit `dde833b57ee66ee046bf1e67bc097a3a9a588ebd`. The preserved upstream MIT license is included as `LICENSE-NEU.txt` alongside this file.
- Hypixel SkyBlock Wiki and its contributors: https://hypixelskyblock.minecraft.wiki/. The source snapshot records CC BY-NC-SA 3.0 (https://creativecommons.org/licenses/by-nc-sa/3.0/) and retains revision IDs and attribution references. Wiki-derived adaptations remain subject to those terms.
- Hypixel Public API: https://api.hypixel.net/. Saved public Items, Skills, Collections, Bingo and Election resources were used as source material. These resources do not represent every game display.

Changes made: extraction of visible candidate text, grouping and segmentation of sentences, Japanese translation, preservation of English names, conservative filtering, and exact-key compilation. Only a small sample of game displays has been checked in a Minecraft client; the complete corpus remains unverified. Ambiguous and incomplete source text is excluded.

The source workbench snapshot is build `20261028T171546016395Z`. `candidate.manifest.json` records the input pack paths, hashes and source IDs for reproducibility. Individual source references, pinned Wiki revision URLs and the original NEU license remain in the accompanying source corpus/workbench. This local build has not been published as a release.
